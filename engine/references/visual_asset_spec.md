# 视觉资产维度规范

本规范用于在拆书过程中提取“可转化为图片、漫画分镜、短剧分镜、角色卡、场景概念图”的视觉生产资料。

> 视觉资产只来自原文或章节分析证据，不允许为了好看补不存在的服装、场景、动作、人物关系或镜头。

> v12.1 起，`scripts/compress_tags.py` 会把所有带受控前缀的标签（含 `画面类型:`、`视觉用途:`）从 `标签集` 下层到 `详情.补充标签`。后续查询视觉资产候选时，应同时检索元素的 `标签集` 和 `详情.补充标签`（后者是 JSON 字符串数组，需用 `parse_supplementary_tags` 解析）。

## 与故事结构 JSON 的关系

视觉维度不新增顶层 `图片集`。推荐三层承载：

1. `事件集.标签集`：放可检索的视觉入口，如 `画面类型:冲突对峙`、`视觉用途:封面候选`、`爽点情绪点:打脸`。
2. `事件集.详情`：放具体画面生产资料，如 `视觉等级`、`核心画面`、`镜头建议`、`氛围`、`视觉理由`。
3. `全书分析/视觉资产/`：汇总成表格和提示词素材。

## 章节分析新增表

每章章节分析 MD 应包含：

| 候选编号 | 对应事件 | 画面价值 | 画面类型 | 核心画面 | 出场人物 | 地点 | 关键物品 | 情绪氛围 | 镜头建议 | 是否进入视觉资产 |
|----------|----------|----------|----------|----------|----------|------|----------|----------|----------|------------------|

画面价值建议使用 `S/A/B/C`：

- S：封面级、强冲突、强情绪、强辨识度。
- A：适合漫画/短剧关键分镜。
- B：适合章节插图或场景补充。
- C：视觉价值较低，只作为普通剧情记录。

## 事件详情推荐字段

```json
{
  "详情": {
    "视觉等级": "S",
    "画面类型": "冲突对峙",
    "核心画面": "大厅内双方对峙，主角在众人注视下承受羞辱并准备反击。",
    "镜头建议": "中景展示大厅压迫感，随后切主角面部特写。",
    "氛围": "压抑、羞辱、紧绷、反击前夕。",
    "视觉理由": "人物站位明确，情绪强烈，冲突集中，适合作为封面或关键分镜。",
    "视觉用途": "封面候选"
  },
  "标签集": ["画面类型:冲突对峙", "视觉用途:封面候选"]
}
```

注意：`详情` 值只能是 string 或 `类型:名称` 字符串数组。视觉描述字段请写字符串，不要写对象。

## 全书分析输出

视觉资产支持**两种粒度**输出：

### 顶层全书汇总（保留）

```text
全书分析/视觉资产/视觉资产清单.md
全书分析/视觉资产/关键场景分镜表.md
全书分析/视觉资产/AI绘图提示词素材.md
全书分析/视觉资产/角色外观一致性表.md
全书分析/视觉资产/场景氛围表.md
```

### 分章独立产物（v12 新增）

每章一个子目录，文件结构与顶层完全对齐：

```text
全书分析/视觉资产/分章/ch001/
├── 视觉资产清单.md
├── 关键场景分镜表.md
├── AI绘图提示词素材.md
├── 角色外观一致性表.md
└── 场景氛围表.md
全书分析/视觉资产/分章/ch002/...
```

分章产物只引用本章原文与本章分析MD的内容，禁止跨章归纳。顶层汇总由 `--aggregate` 阶段从分章产物 reduce 而来，单章/局部生成**不会**覆盖顶层。

## 质量规则

1. 角色外观必须以原文证据为准；原文没有写的外观标“待确认”。
2. 不把普通事件都强行升为视觉资产；优先选择冲突集中、场景明确、情绪强、人物关系清楚的事件。
3. AI 绘图提示词素材只给构图、人物、地点、动作、氛围，不添加原文不存在的设定。
4. 视觉资产表必须引用 `事件:名称`、章节号和证据来源。
