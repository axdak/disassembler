# 受控故事运行时实施方案

> 执行方式：本会话原生执行，使用 executing-plans 和 TDD，按任务记录验证结果。用户已要求按审计顺序给出方案并开始实施，沿用该授权，不再逐阶段请求确认。

**Goal:** 降低章节 Delta、周期治理和修复中的重复模型工作，同时保证正式数据只在校验后发布，失败可续接。

**Architecture:** 保留 CodeBuddy、冻结证据和现有合并/提交链。MCP 统一身份规则，提供有界领域读取和持久化候选；候选校验反馈在同会话返回，宿主仍是正式发布的唯一责任方。

**Tech Stack:** Python 标准库、现有 JSON 校验器、stdio MCP、CodeBuddy CLI、React；不新增依赖。

**Spec:** `docs/2026-10-13-architecture-audit.html` 与本文件接口约定。

## 约束与执行裁定

- 保留开始前工作区全部修改；基线保存于 `.workbuddy/runtime-implementation/baseline`。在 `codex/controlled-story-runtime` 分支工作，避免改变 main 的分支指针。
- 不重启运行中的任务，不修改用户正在拆解的书籍；验证使用临时项目。
- 不凭相似名字自动合并，不通过删除历史、放宽校验或跳过审计提速。
- 原始材料可查询不等于必须全部放进一次提示词；分页明确返回未读完状态，绝不静默截断。
- 现有其他 provider 和手工任务保持兼容。新路径只对宿主明确登记的 CodeBuddy 任务启用；异常拒绝交付，不用未验证候选冒充成功。
- 不发起提交：管理ID尚未提供，且已有其他修改；交付可审查的工作区差异。
- 固定输入离线测试可证明工程约束，不能证明模型语义正确率或实测提速倍数。真实模型评测与独立介质备份需要实际运行/备份环境，单独标记验证边界。

## 接口约定

- `ContextReader.story_get_units` 复用 `element_identity.build_lookup_index/find_index`。
- 领域读取包含冻结版本、字段路径及分页游标；每次返回有硬上限，完整数据保留在快照。
- 候选账本存储任务指纹、冻结故事版本、候选版本、操作ID及参数摘要。相同操作重试返回原回执；相同ID不同参数、过期候选版本被拒绝。
- `candidate_stage` 接收标准 Delta/治理候选；`candidate_validate` 复用现有权威校验；只对通过校验的确切候选摘要签发完成凭证。正式合并和保全检查仍由现有宿主链执行。
- `candidate_patch` 只修改候选内部已有路径或受允许的新字段；不接受任意文件路径，不写原始证据或正式故事。
- 章节提交和治理提交复用项目级跨进程互斥，在发布前校验基线摘要。重启后先核对回执，避免重复合并。
- 任务记录覆盖排队、执行、校验、提交及重试；容量、读取、候选和修复资源限额分别有明确失败原因。

### 第二阶段实测与审查

合成原文为一章《夜航信》：宁川在青石渡口发现匿名信，信要求明晚携铜钥匙赴旧钟楼；钥匙未获得、尚未赴约、父亲只被提及。每组输入故事摘要核对一致，Delta原文与分析逐字节一致。调用真实CodeBuddy；单次超时240秒、CLI配置max-turns=12，无派发内重试。下表记录生成耗时，正式提交耗时未包含；模型用量未取得，预算中的tokens为估算，不能作为计费用量。

| 任务与路径 | 生成耗时 | 累计领域工具调用 | 结果 |
| --- | ---: | ---: | --- |
| Delta 旧路径 | 73.047秒 | 未统计 | 生成及正式提交成功 |
| Delta 首版受控 | 191.812秒 | 15 | 生成及正式提交成功 |
| Delta 合并提交工具后 | 144.782秒 | 7 | 生成及正式提交成功 |
| 周期治理旧路径 | 169.750秒 | 未统计 | 生成返回0，但标签守恒校验失败，正式提交被阻止 |

| 周期治理合并工具后首试 | 241.656秒 | 10 | 超时，私有候选保留，未提交 |

- Delta受控路径本次比首版减少约24.52%耗时、53.33%工具调用，但仍约为旧路径1.98倍。治理受控路径两次派发累计生成436.796秒，不能仅用续跑195秒计算加速。样本数为1，不能报告P50/P95或总体正确率提升。
- 运行时优化：增加`candidate_submit`，一次保存候选、校验并签发凭据；宿主注入候选状态与集合计数，减少重复元数据查询。旧候选操作仍兼容。
- 恢复安全：独立审查发现结构合法的临时探测候选可能被误作最终交付。现将工具校验成功`completed`与宿主确认最终StructuredOutput的`accepted`分离，仅后者可免模型复用；任何候选修改都会清除该确认。已先观察回归测试失败，再修复通过。审查未发现剩余Critical/Important。
- 维护安全：真实跨进程竞争测试覆盖8个公共入口；工作台规范化、迁移和恢复等待同一锁。恢复非零返回和异常均在锁内还原原过程库；终稿替换中断保留旧终稿。模型运行不占用项目写锁。
- 事实核对：固定断言检查主角正式名、事件参与成员、事件发生地点。旧路径仅名称通过，两个结构关系字段缺失（相关事实仍有文字描述）；优化受控路径3项均通过。两者均未把铜钥匙写为已获得或把旧钟楼写为已到达，但都出现原文未直接支持的场景氛围描述。本次结构校验和三个标注不能证明完整语义正确。
