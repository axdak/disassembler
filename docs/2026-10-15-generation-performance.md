## 已实现

1. **完整材料复用**：宿主只对实际已内嵌全文的冻结材料标记 `provided_in_prompt`。比较仅归一 CRLF/LF，部分引文不会命中。重复读取返回定位及摘要回执，不再次返回正文。未内嵌证据继续正常分页；上下文丢失时可显式 `reread=true` 恢复冻结全文。
2. **提前提供材料目录**：首轮提示包含冻结材料路径及是否已经提供，减少为定位路径而付费调用目录工具。追加的目录、状态与原生 schema 均重新计入容量门禁。
3. **一致的并发设置**：分析和分章线程池使用任务配置；交错执行额外包含串行 Delta 消费者的一个名额。上下文随线程复制并在结束时复位，不修改进程环境或另一个任务的配置。明确设置的 `ND_MAX_CONCURRENT_WORKERS` 仍作为部署上限；未配置任务的独立调用保留默认上限 2。共享 FIFO、取消和异常释放保留，日志报告实际限制。
4. **完整交付后收尾**：原生完整成功信封到达后立即进入宿主接收及原有校验，不再等待 CLI 自身退出。半截工具参数和缺少根级必需部分的内容不能触发提前成功；不补空集合、不合成事实。
5. **失败信封及时拒绝**：即使 CLI 最后退出码为 0，只要明确返回失败终态，也立即拒绝其附带内容。输出截断与显式轮数上限保持原有分类优先级。最终信封到达时再次检查 CLI 的输出截断标记，防止快速收尾漏掉刚写入的 `length` 元数据。
6. **长尾与不完整提交诊断**：记录首个 CLI 事件、事件间隔、当前沉默时间、消息标识计数，以及完整提交的字段名、缺失根字段、参数字符数和摘要。关联临时会话名，方便核对模型请求日志。不记录正文或推理内容。诊断心跳不视作模型进展，不因为等待较长就自行增加重跑。
